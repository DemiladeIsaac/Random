# Demilade Olorode — Anime-inspired portfolio

A responsive React + Vite portfolio using Tailwind CSS, Framer Motion and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

## Build for deployment

```bash
npm run build
npm run preview
```

Deploy the project root to Vercel or Netlify. The Vite build output is `dist`.

## Project screenshots

- `public/images/ede.png` is the supplied Èdè screenshot.
- Add the real screenshots for the remaining projects using these exact filenames:
  - `public/images/comicverse.png`
  - `public/images/fashionista.png`
  - `public/images/secret-message.png`

Until those files are added, the project cards display custom anime-inspired placeholder previews. The placeholders are intentionally self-contained and will automatically be replaced when the corresponding image files are added.

## Personal details

Update project descriptions, experience, skills and links in `src/data/projects.js` and `src/App.jsx` as needed. The CV-based content is drawn from the supplied CV. Phone and email are shown in the contact section; LinkedIn and GitHub links open in a new tab.
